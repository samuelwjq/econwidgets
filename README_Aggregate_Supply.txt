AGGREGATE SUPPLY FACTORS
Open Aggregate_Supply_Factors.html with all supplied JS/CSS alongside it.
Upload the 11 web files to the existing repository root. README is optional.
No index.html is included or changed. The shared files are unchanged.

Movement along AS: select A on horizontal SRAS, intermediate AS or vertical
LRAS. The movement slider fixes A and moves B continuously along unchanged AS,
including across sections. It selects curve position, not a unique price shock.
Coordinate guides are always shown. These points need not be equilibria.

Shifts: labour/raw-material costs change SRAS. Exchange-rate increases mean
appreciation, lowering imported-input costs and shifting SRAS down. AD is fixed.
Resources change LRAS only. Productivity changes BOTH costs (SRAS) and capacity
(LRAS). Declines reverse the effects. AD is optional and hidden by default.
When displayed, fixed AD determines initial/new equilibrium outcomes.

Shared summary-strip sizing: 28px normally; 40px at <=480px viewport width.
No multiplier, calibration, external assets or runtime network fetches.

Checks: JS syntax; 305 factor states and 1001 movement positions; browser
loading, movement control, mode switching, productivity and Show AD controls.
Full physical touch, native fullscreen and clipboard compatibility, exhaustive
label states and phone layouts have not been certified for this new widget.
